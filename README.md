# Novo site da Gaia — base para o Antigravity

Primeira versão executável do novo site da Gaia Vida Ainda. O projeto já contém a identidade atual, fotografias extraídas do site existente, conteúdo preliminar, rotas planejadas, formulário protegido e preparação para Cloudflare.

## Começar

Requisito: Node.js 22.12 ou superior.

```bash
npm install
cp .env.example .env
npm run dev
```

Abra `http://localhost:4321`.
